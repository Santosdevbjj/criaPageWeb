# 🌐 Projeto: Criação de Página Web com HTML Básico

Este projeto faz parte do Desafio de Projeto proposto pela plataforma DIO, onde o objetivo é construir um website simples utilizando as principais tags HTML aprendidas durante o módulo introdutório.

---

# 📌 Objetivo do Projeto

Criar uma página Web utilizando:

- Tags básicas de texto
- Listas ordenadas e não ordenadas
- Links
- Elementos de destaque
- Tags adicionais pesquisadas
- Estrutura semântica simples

O projeto foi versionado e publicado neste repositório para fins de avaliação e estudo.

# 🧪 Tags HTML Utilizadas

Durante o projeto foram utilizadas:

### **Tags obrigatórias do desafio**
- `h1` até `h6`
- `p`
- `i`, `u`, `strong`, `small`
- `mark`
- `ol`, `ul`, `li`
- `a`
- `hr`
- `sub`, `sup`
- `blockquote`

### **Tags adicionais sugeridas**
- `font`
- `del`
- `abbr`

---

# 💡 Requisitos de Hardware e Software

### **Hardware mínimo**
- 4 GB RAM
- 2 GB livres em disco
- Processador Dual Core

### **Software necessário**
- Sistema operacional Windows, Linux ou macOS
- **Visual Studio Code** (ou qualquer editor de texto)
- **Git instalado**
- Navegador (Chrome, Edge, Firefox, etc.)
